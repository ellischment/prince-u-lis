### Шаг 0.3 (вход в панель и роли) — готово

- lib/auth.ts: bcrypt (12 раундов), сессия в httpOnly cookie на 14 дней, sameSite lax, secure в проде. Сессия сверяется в базе при каждом обращении, а не только по подписи: завершение сессий владельцем будет срабатывать сразу

- lib/roles.ts: 17 разделов панели по SPEC р. 13, три из них (настройки, журнал действий, система) только для owner и tech по таблице ARCHITECTURE р. 6
- proxy.ts закрывает всё /admin кроме входа, проверяя наличие куки. Подлинность сессии проверяется в layout панели через currentUser
- app/admin/(panel)/[section]/page.tsx: заглушки всех разделов с серверной проверкой роли. Неизвестный раздел даёт 404
- В seed заведены двое: владелец и администратор, пароли только из переменных окружения, короче десяти символов не принимаются (SPEC р. 16). Существующие записи обновляются, а не пересоздаются, иначе повторный seed рвёт живые сессии

Проверено вручную в браузере, не только сборкой:

- Вход под администратором: 14 разделов в меню, трёх владельческих нет

- Блокировка: после 5 неудач вход отклоняется даже с верным паролем, с указанием срока. Тестовые записи после проверки удалены

Важное решение по способу сброса. В Next 16 revalidateTag требует второй аргумент, и рекомендованный профиль max отдаёт СТАРОЕ содержимое, пока свежее готовится в фоне. Для панели это неприемлемо: ARCHITECTURE р. 3 требует, чтобы правка была видна сразу. Взят updateTag, он обнуляет запись немедленно и вызывается только из серверных действий. Проверено опытом, а не по документации.

Проверено на боевой сборке (npm run build и npm start), не в режиме разработки: в dev кэш почти не работает и тест ничего не доказывает.

### Шаг 1.1 (каталог занятий и страница занятия) — готово

- Галерея по FEATURES р. 1.4: одно крупное и четыре мелких, метка «ещё N», просмотр на весь экран со стрелками, клавишами, миниатюрами, закрытием по Esc и по нажатию мимо кадра. Прокрутка страницы блокируется. Видео открывается там же встроенным плеером площадки, на сервер не загружается. Ноль медиа даёт заглушку, просмотрщик не открывается
- Закреплённая полоса с ценой и кнопкой записи на узком экране при прокрутке
- lib/price.ts: цена и длительность разбираются из текста для разметки. «от 3 500 ₽» даёт 3500 и minPrice, «2 часа» даёт PT2H. Строка без числа не выдумывает цену, поле просто не выводится. Девять тестов
