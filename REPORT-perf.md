# REPORT: Оптимизация производительности сайта

## Что было сделано

### Проблема

Сайт показывал пустую страницу на медленном интернете. Причина: CSS-правило `.reveal { opacity: 0 }` скрывало всё содержимое страницы до загрузки JavaScript (108 kB). На плохом соединении пользователь мог видеть пустой экран несколько секунд.

### Исправления

**1. Progressive enhancement для скролл-ревила (главное)**

Убрали `opacity: 0` из CSS — контент теперь видимый по умолчанию. JavaScript скрывает только элементы вне viewport и только после загрузки. Элементы, уже видимые при загрузке JS, не мигают.

Было:

```css
.reveal {
  opacity: 0;
  transform: translateY(26px);
} /* скрывает всё до JS */
```

Стало:

```css
.reveal {
  /* только transition, без скрытия */
}
```

JS (useReveal / RevealInit) применяет скрытие только к элементам ниже экрана.

**2. Конвертация 6 секций в server components**

Убрали `'use client'` и зависимость от `useReveal` из статичных секций:

- TrustBand
- AtmosphereSection
- ScheduleSection
- WhatIfSection
- PromosSection
- FaqSection

Их JavaScript-код теперь не отправляется браузеру. Сервер рендерит HTML напрямую.

**3. RevealInit.tsx — один глобальный observer**

Создан лёгкий клиентский компонент (`RevealInit`), который обслуживает анимации для всех server-component секций через `[data-reveal-group]` атрибут. Заменяет 6 отдельных IntersectionObserver'ов одним.

**4. Ленивая загрузка BookingSection**

Форма записи (самый тяжёлый компонент) теперь грузится отдельным чанком через `next/dynamic({ ssr: false })`. Не влияет на начальную загрузку страницы — форма появляется когда пользователь доскроллил до неё.

**5. Шрифт Manrope — конкретные начертания**

Вместо variable font (все веса) — только нужные: `['400', '500', '600', '700']`. Меньший файл шрифта.

**6. Cache-Control для статических ассетов**

В `next.config.mjs` добавлен заголовок `Cache-Control: public, max-age=31536000, immutable` для `/_next/static/*`. При повторных визитах ассеты берутся из кэша браузера без сетевого запроса.

## Результат

| Метрика             | До                  | После                |
| ------------------- | ------------------- | -------------------- |
| First Load JS (/)   | 108 kB              | 106 kB               |
| Контент видим до JS | Нет (пусто)         | Да (сразу)           |
| BookingSection      | В начальном bundle  | Отдельный lazy chunk |
| Статичные секции    | `'use client'` + JS | Server HTML, нет JS  |

Ключевое улучшение — не в kB, а в воспринимаемой скорости: пользователь видит контент немедленно после загрузки HTML+CSS, не дожидаясь JavaScript.
