# Панель сайта: инструкция для команды студии

Этот документ разделён на три инструкции по ролям, чтобы каждый читал только своё. Содержимое перенесено полностью, ничего не потеряно.

- **Владелец студии**: `instrukciya-vladelec.md`. Вход, ежедневная работа, доступы сотрудников, разделы только для владельца, правила публикации, что делать при сбое.
- **Администратор** (ведёт наполнение): `instrukciya-administrator.md`. Разбор каждого раздела панели по порядку, требования к файлам, частые ошибки.
- **Технический администратор**: `instrukciya-tehadmin.md`. Сервер, выкатка, резервные копии, пароли, известные грабли, быстрая диагностика.

Смежное: `foto-pamyatka.md` (требования к фото), `integracii-amocrm-telegram.md` (amoCRM и Telegram), `amocrm-dlya-vladeltsa.md` (работа с заявками).
