# Перечень используемых сторонних библиотек

Приложение к передаче результата работ (Техническое задание, раздел 27).
Состав на дату передачи: 9 сентября 2026, версия сайта в репозитории — ветка
`main`. Точные версии всегда лежат в `package.json` и `package-lock.json`.

Все библиотеки распространяются по разрешительным лицензиям с открытым кодом
(MIT, Apache 2.0, BSD, MPL). Ни одна не требует оплаты, раскрытия исходного
кода студии или отчислений. Ограничений на коммерческое использование нет.

## Внешние сервисы, а не библиотеки

Работают по своим условиям, оформлены на студию и оплачиваются ею:

- **amoCRM** — заявки с сайта уходят сделками, аккаунт студии.
- **Telegram Bot API** — уведомления в командный чат, бот студии.
- **Яндекс.Метрика** — счётчик подключается идентификатором из настроек,
  код на сайте готов и ждёт номер счётчика от студии.
- **Let's Encrypt** — бесплатный сертификат HTTPS, обновляется сам.
- **Шрифты Cormorant Garamond, Manrope, Neucha** — открытая лицензия SIL OFL,
  файлы лежат на сервере студии, к внешним сервисам сайт за ними не ходит.

## Как проверить самостоятельно

В папке проекта:

```
npm ls --omit=dev --depth=0
```

Полный список с зависимостями зависимостей — `package-lock.json`.
