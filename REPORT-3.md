### Компоненты панели

- `AdminSidebar` — sticky сайдбар с nav-ссылками на тёмном фоне (`#101e39`); активная ссылка выделена кремовым; ссылки «Журнал» и «Настройки» видны только `owner`; кнопка «Выйти» через `signOut`
- `BookingFilters` — клиентский фильтр: поиск по имени/телефону (debounce 400ms), dropdown статуса, date-range; кнопка «Сбросить»; обновляет URL через `useRouter`
- `BookingActions` — кнопки смены статуса (`confirmed`, `done`, `no_show`, `cancelled`, `new`), PATCH на `/api/admin/bookings/[id]`, `router.refresh()` после ответа
- `TogglePromo` — кнопка переключения активности акции
- `ContentEditor` — textarea с кнопкой «Сохранить», PATCH на `/api/admin/content/[key]`, flash «Сохранено»
- `ChangePasswordForm` — форма смены пароля с клиентской валидацией (совпадение, длина ≥ 8)

### API-маршруты (все требуют сессии)

| Маршрут                        | Метод | Описание                                                                              |
| ------------------------------ | ----- | ------------------------------------------------------------------------------------- |
| `/api/admin/bookings`          | GET   | Список записей с фильтрами (status, search, dateFrom, dateTo, page), пагинация 25/стр |
| `/api/admin/bookings/[id]`     | PATCH | Смена статуса; пишет AuditLog; обновляет `visitsCount` при переходе `done`            |
| `/api/admin/promotions/[id]`   | PATCH | Переключение `active` акции                                                           |
| `/api/admin/content/[key]`     | PATCH | Обновление текста по ключу                                                            |
| `/api/admin/settings/password` | POST  | Смена пароля: проверяет текущий через bcrypt, обновляет хэш                           |

## Решения

- **Sidebar без infinite redirect**: layout проверяет сессию — при её отсутствии рендерит минимальную обёртку, middleware уже сделал редирект до layout'а
- **visitsCount автоматически**: при PATCH статуса в `done` — increment; при откате из `done` — decrement
- **Фильтры через URL**: `BookingFilters` читает и пишет searchParams, страница — Server Component, данные всегда свежие после `router.refresh()`
- **Разграничение ролей**: `owner` видит «Журнал» и «Настройки», `admin` — нет; middleware дублирует защиту на уровне роутинга
